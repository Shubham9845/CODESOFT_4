# ✊✋✌️ Rock Paper Scissors Game (GUI)

A desktop-based Rock-Paper-Scissors game built using **Python Tkinter**, allowing users to play against the computer with score tracking.

## 🚀 Features
- Play against computer (random choice)
- Real-time result display (win/lose/tie)
- Score tracking system
- Simple and interactive GUI

## 🛠️ Technologies Used
- Python
- Tkinter (GUI)

## ▶️ How to Run
1. Install Python
2. Clone the repository:
   git clone https://github.com/Shubham9845/rock-paper-scissors-tkinter.git

3. Run the program:
   python rps_game.py
